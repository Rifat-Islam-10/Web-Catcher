 # 🕷️ Web Catcher – Spider-Man Game

A simple Spider-Man inspired catching game built using Python using its game and GUI module. 
Control Spider-Man and catch falling Gwen Stacy to score points and save her.


🛠️ Tech Stack

* Python
* Tkinter
* Canvas & Event Handling

✨ Features

* 🎮 Interactive keyboard controls
* 🕸️ Catching mechanism
* 🎯 Score tracking
* ⚡ Real-time object movement
* 🖥️ Simple GUI

🚀 Run the Game

python web_catcher.py

🎯 Objective

As a Marvel Studio fan I been obsessed with Sider Man, so I really wanted to make a simple game using my programming skills as a fun task.
So I turned my vision into this.

The game is designed as a beginner-friendly Python project to demonstrate how programming logic can be combined with a graphical interface to create an interactive application and have fun.

📚 Learning

This project helped me practice Python, GUI development, event handling, collision detection, animation, and basic game logic.
